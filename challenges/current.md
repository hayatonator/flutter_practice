# 課題: メモ帳アプリ（UX強化版）

## 難易度
Level 6 — ウィジェット応用・UX改善

## 概要
メモを管理するアプリを作る。これまでの課題では削除ボタンをタップしていたが、今回は「スワイプで削除」「削除確認ダイアログ」「ボトムシートでの追加」という3つのUXパターンを実装する。リスト操作のUXを本格的に改善することが目的。

## 機能要件
- [ ] メモ一覧をListView.builderで表示する（メモにはタイトルと本文がある）
- [ ] 各メモを左にスワイプすると削除できる（Dismissible）
- [ ] 削除前にAlertDialogで「本当に削除しますか？」の確認を出す。キャンセルした場合はメモを元の位置に戻す
- [ ] 画面右下のFAB（FloatingActionButton）をタップするとボトムシートが開く
- [ ] ボトムシート内にタイトル・本文のテキストフィールドがあり、「追加」ボタンで保存・ボトムシートを閉じる
- [ ] タイトルが空欄のまま「追加」を押した場合はエラーメッセージを表示する（ボトムシートを閉じない）
- [ ] メモが0件のときは「メモがありません」という空状態メッセージを表示する

## 技術要件
- 使うべきWidget・クラス:
  - `Dismissible` — スワイプ削除
  - `showDialog` + `AlertDialog` — 削除確認
  - `showModalBottomSheet` — メモ追加UI
- 状態管理: ChangeNotifierProvider（これまでと同様）
- ファイル構成:
  ```
  lib/memo/
  ├── memo_model.dart     ← Memoクラス、MemoNotifier
  └── memo_page.dart      ← UI
  ```

## 完了判定チェックリスト
- [ ] 左スワイプするとAlertDialogが表示される
- [ ] ダイアログで「キャンセル」を押すとメモが消えずに残る
- [ ] ダイアログで「削除」を押すとメモが一覧から消える
- [ ] FABをタップするとボトムシートが下から出てくる
- [ ] ボトムシートでタイトル・本文を入力して「追加」を押すとリストに追加される
- [ ] タイトル未入力で「追加」を押すとエラーが表示されボトムシートが閉じない
- [ ] 全メモを削除すると「メモがありません」が表示される

## 今回の学習ポイント
`Dismissible`・`showDialog`・`showModalBottomSheet` という3つの定番UIパターンを習得する。特に`Dismissible`のキャンセル処理（`confirmDismiss`コールバック）の扱いが重要なポイント。
